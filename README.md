# Spots

this project called spots is used to showcase skills obtained threw tripleten bootcamp and further progress in the lessons

## description

a website project, that in the current state updates to a project called Spots, which displays image-based avatars with names and descriptions. what it does is it uses webpack with a dev setup and added APIs with node modules to pull requests and save information to a server. its used to demonstrate editing an entry, changing the name, description, and avatar photo, and then showing that a new post (including one for Elon Musk) persists after the site is closed and reopened. it concludes by confirming the saved image and data continue to work as expected.
